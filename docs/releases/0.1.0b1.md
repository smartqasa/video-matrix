# Video Matrix 0.1.0b1

Initial beta preview for Home Assistant 2026.9 or newer.

- No Hassle NHAV-8X16V5 support with eight independent HDMI/HDBaseT output pairs.
- Device-stored input/output names and `allsource` routing feedback.
- Standard media-player source selection with serialized, confirmed read-back.
- Shared polling, external route changes, and unavailable/recovery handling.
- UI setup, optional source-name overrides, and connection reconfiguration.
- Separate driver interface for future matrix brands.

Install by adding `https://github.com/smartqasa/video-matrix` to HACS as an
**Integration**. Download `0.1.0b1` with beta versions enabled, or use `main` for
the initial preview. Restart Home Assistant if requested, then add **Video Matrix**
under **Settings → Devices & services**.

The default branch now contains a complete integration, fixing HACS's
“Repository structure for main is not compliant” error.

Validation: the 65 automated tests pass against Home Assistant 2026.9.1, including
a simulated HTTP device. Physical switching and feedback on the NHAV-8X16V5 still
need the hardware acceptance checks in `docs/testing.md`. Existing No Hassle
entities are not automatically migrated or replaced.
